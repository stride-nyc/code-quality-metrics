# Font Attribution

The font files in this directory are vendored, latin-only, static woff2
subsets sourced from Google Fonts:

- Big Shoulders Display (weight 800): `big-shoulders-display-800.woff2`
- Public Sans (weights 400, 600, 700): `public-sans-400.woff2`,
  `public-sans-600.woff2`, `public-sans-700.woff2`
- IBM Plex Mono (weights 400, 600): `ibm-plex-mono-400.woff2`,
  `ibm-plex-mono-600.woff2`

All three font families are licensed under the SIL Open Font License,
Version 1.1.

Source: https://fonts.google.com/
